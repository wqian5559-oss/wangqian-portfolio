## 2. 项目背景

wangqian 需要一个面向求职场景的个人作品集网站，用于向招聘方、面试官或潜在合作方集中展示个人信息、项目案例与联系方式。网站应比普通简历更具视觉表达力，也比社交主页更聚焦职业能力、项目成果和个人潜力。

网站当前定位为：面向“产品运营 / 内容运营 / 产品经理”岗位的个人作品集，其中主方向优先级为“产品运营 > 内容运营 > 产品经理”。它需要帮助访问者快速判断王千的运营策略、内容表达、产品理解、项目推进能力和结果意识。

## 3. 产品目标

### 3.1 核心目标

- 建立一个专业、有记忆点的个人线上主页。
- 让访问者快速理解王千的求职方向：产品运营 / 内容运营 / 产品经理。
- 通过 4 个项目案例增强求职可信度。
- 提供清晰直接的联系方式与简历下载入口。
- 以“视觉有记忆点，但信息清楚”为第一版设计原则。

### 3.2 非目标

- 第一版不做复杂交互设计展示。
- 第一版不做登录、后台管理、评论、数据看板等产品化功能。
- 第一版不追求复杂动效，优先保证内容表达、视觉气质和移动端适配。
- 第一版不把网站做成完整博客或内容社区。

## 4. 目标用户

### 4.1 主要用户

- 招聘方 HR
- 产品 / 运营岗位面试官
- 潜在合作方
- 通过简历、社交平台或作品链接访问网站的人

### 4.2 用户核心诉求

- 快速判断候选人的专业方向与能力边界。
- 查看候选人的代表项目与实际产出。
- 理解候选人在项目中的角色、思考过程和成果。
- 获取简历、邮箱或其他联系方式。
- 在较短时间内形成清晰且正面的职业印象。

## 7. 内容语言策略

- 网站语言：中文为主，少量英文点缀。
- 导航可使用英文：Home / About / Case Study / Contact。
- 正文以中文表达，保证招聘方快速阅读。
- 标签、短句、视觉装饰性文案可使用英文，例如 Product Thinking、Content Strategy、Growth Mindset。
- 首页首屏文案暂用占位符，后续根据个人经历再精修。
